Automatic booking

Valid package submissions are automatically approved and registered with a tracking number. This console is not used to approve, reject, or manually create bookings.

Location updates

Set the transport mode, enter the current coordinates (or click the map), and save a status. Only save locations that reflect a real recorded update.

Email links

After you save a shipment movement/location update, the notification function attempts to email the sender and receiver. If email cannot be confirmed, check the Brevo API key and verify work@facil-hub.online in Brevo.
